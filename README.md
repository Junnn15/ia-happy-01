# ai-happy-01 — A Little Robot's Sunflower

A tiny copper robot waters a sunflower growing through a crack in a city
sidewalk at golden hour, gazing up at the bloom with joy while a small bird
perches on the petals. Warm light, soft bokeh city behind — a small act of
care that made something beautiful grow where nothing was supposed to.

`main.py` (Python 3.13, standard library only) copies the image shipped in
this repo (`entry.png`) to `/output/entry.png`. The copy is byte-for-byte,
so both graded runs write identical bytes.
